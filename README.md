## ▶️ Getting Started (Run Locally)

Pick the section that matches your project type.

General (static site)
```bash
git clone https://github.com/Muskangautam8933/Portfolio.git
cd Portfolio
# open index.html or serve with a simple server
```

Node / React / Next.js
```bash
git clone https://github.com/Muskangautam8933/Portfolio.git
cd Portfolio
npm install
# for Next.js
npm run dev
# for Create React App
npm start
```

Build for production
```bash
npm run build
# then deploy contents of /build or /.next depending on framework
```
